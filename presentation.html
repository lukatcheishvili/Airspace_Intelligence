Feature Engineering
Trajectory Feature Engineering
Transforming raw ADS-B snapshots into ML-ready fixed-length vectors
⏱ Segment Detection
Gaps >30 min in flight_key splits one ICAO24 into multiple independent segments. Minimum 8 snapshots required per segment.
📍 Start / End Position
start_lat/lon and end_lat/lon encode the entry and exit vector through Iberian airspace — the primary clustering signal.
✈ Flight Type
Airport proximity UDFs (Haversine / flat-Earth) classify each segment as departure, arrival, hop, or pass-through. Hops are excluded.
📏 Altitude Features
min_alt, max_alt, mean_vrate capture flight phase (cruise, climb, descent) as secondary features for the deviation classifier.
🗺 Trajectory Resampling
Raw trajectories (variable length) are resampled to exactly 15 waypoints via linear interpolation → 30-dimensional feature vector [lat₀,lon₀,…,lat₁₄,lon₁₄].
📐 StandardScaler
All 30 waypoint features normalised to zero mean / unit variance using Spark MLlib StandardScaler before clustering and classification.
Flight types found: 40 arrivals · 57 departures · 29 hops (excluded) · 346 pass-throughs
Part II — Corridor Clustering
Bisecting K-Means Corridor Discovery
PySpark MLlib · BisectingKMeans · Silhouette score optimisation
🔀
Why BisectingKMeans?
Divisive algorithm — iteratively bisects the largest cluster. More deterministic and balanced than standard K-Means. Reveals hierarchical corridor structure (e.g. Atlantic → Lisbon vs Porto).
⚙️
ML Pipeline
1. VectorAssembler (30-dim waypoint vector)
2. StandardScaler (zero mean, unit variance)
3. BisectingKMeans (k sweep)
4. ClusteringEvaluator (Silhouette)
🏆
Corridor Labels
Each cluster corresponds to a distinct air corridor — a group of flights sharing similar spatial trajectories. Labels drive the corridor-deviation classifier in Part III.

Part III — Deviation Classifier
Random Forest Corridor Deviation Classifier
Supervised classification of flights deviating from expected corridors
🏷️
Label Generation
Flights far from their cluster centroid (above a distance threshold) are labelled deviating; close flights labelled on-corridor. Labels produced automatically from BKMeans output.
🌲
RandomForestClassifier
PySpark MLlib RandomForestClassifier trained on the same 30-dim waypoint features plus altitude features. Ensemble of trees for robust generalisation on sparse real-world data.
📊
Evaluation
MulticlassClassificationEvaluator with accuracy and weighted F1 score. Pipeline includes StringIndexer + IndexToString for label handling.
